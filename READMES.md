# Portfolio

Static personal portfolio site for Lokesh Dhakal.

## Getting started

1. Install dependencies (none required).
2. Open `index.html` in your browser, or start a simple server:
   ```bash
   cd portfolio
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000` to view the portfolio.

### Features
- Light, single-page layout with smooth scroll and active nav highlighting
- Mouse tracker (desktop), modal project details, and schema metadata
- Print-friendly Resume/CV/Statement: click **Download Resume** (nav/hero) or **Print Statement** to open print view and save as PDF
- Content is editable via the embedded JSON in `#cms-data` within `index.html`
